This standalone example models the Hugging Face incident described in the cited investigation. It preserves uncertainty and incomplete prerequisite groups; it is not a claim that every modeled connection was observed. [@metr-huggingface-investigation]

The nodes in this example come from a single incident and are meant as an illustration of how the threat modeling toolkit works. The toolkit can be used to build maps of other systems and incidents, with their own nodes, prerequisites, sources, and case studies.

The source code for the toolkit and this example is on GitHub at [aidankierans/threat-map-app](https://github.com/aidankierans/threat-map-app).
